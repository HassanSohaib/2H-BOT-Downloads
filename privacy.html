Privacy Policy

How 2H BOT handles data.

Last updated: September 2026. This page describes the data handled by the 2H BOT Windows application and this official download website.

Data entered in the application

2H BOT can handle the campaign details you enter, such as listing titles, prices, descriptions, categories, conditions, photos, locations and optional spreadsheet data. These details are used by the application on your local PC to build and manage the campaign workflow you choose.

Session and profile data

When you choose to use an account session, the application can store session/cookie information in bot-managed local browser profiles so the selected automation session can run. The application is designed to keep these bot-managed profiles separate from the personal Chrome Default profile.

Website data

The official download website is a static site. It does not provide a customer account form, payment form or public upload feature. Standard hosting providers may process normal technical request information, such as IP address and browser data, to deliver the site securely.

Sharing and protection

Do not share cookies, passwords or license keys with anyone. Protect your Windows account and the folders where you store the app and campaign files. Contact support only with non-sensitive troubleshooting information such as a screenshot or error message.

Your choices

You can remove local campaign data and bot-managed profile data from your own PC. You can also stop a running task using the application’s Stop control.

No software can promise absolute security. Your own Windows security, account security settings and responsible use remain important.
